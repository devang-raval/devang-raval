### ⚙️ Data Engineering

#### [🏥 FHIR API Data Ingestion & Analytics Pipeline](https://github.com/devang-raval/fhir-databricks-pipeline)
`Azure Databricks` · `PySpark` · `Delta Lake` · `Unity Catalog` · `SCD Type 2`

An end-to-end Medallion pipeline (Raw → Bronze → Silver → Gold) that pulls healthcare data from a public FHIR R4 API. It runs incremental daily loads with pagination and keeps full record history with SCD Type 2. Every run is logged to a Delta table, and the Gold layer serves reporting-ready views.
